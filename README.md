Project Title: Machine Learning-Driven Discovery of HIV-Integrase Inhibitors

Project Summary: This project harnesses the power of machine learning to accelerate the discovery of novel drug candidates targeting HIV. By leveraging the Quantitative Structure-Activity Relationship (QSAR) technique, I developed a predictive model that correlates the molecular structure of chemical compounds with their biological activity against HIV-Integrase, a crucial protein for viral replication.

Project Details:

Data Acquisition and Preprocessing: I utilized pandas and NumPy to process data from the ChEMBL database.

Feature Engineering: RDkit was employed to calculate molecular descriptors, quantifying key structural features of the compounds.

Exploratory Data Analysis: Seaborn and Matplotlib were used to visualize the data, identify trends, and gain insights into the relationships between molecular properties and activity.

Model Training and Validation: A Random Forest machine learning model was trained using scikit-learn to predict the biological activity of compounds based on their molecular descriptors.

Target: in-silico HIV-Integrase Protein

Impact: This project demonstrates the potential of machine learning to streamline the drug discovery process, offering a cost-effective and efficient approach to identify promising drug candidates for HIV treatment. By accurately predicting the activity of chemical compounds, this model can significantly reduce the time and resources required for traditional drug screening methods.
